# Help Center black chrome

The Help Center YFA logo now uses a darker chrome treatment on white. The existing PNG is unchanged; CSS lowers brightness and adjusts contrast while preserving source shading, transparency, dimensions and proportions. The rule applies only to the supplied YFA image inside Support logo placements, including the header, footer and mobile-menu button.

All nine Support pages load a versioned stylesheet URL so the update replaces the cached silver treatment. Other sites, image assets, text, page layout and controls are unchanged.

[Desktop before/after](desktop-comparison.png) · [Mobile before/after](mobile-comparison.png)

Local Chromium checks at 1440px and 390px verified all nine pages load the logos with the black-chrome filter and have no horizontal overflow. Before/after logo bounding boxes are identical. This is a visual contrast improvement; no formal WCAG conformance claim is made.
